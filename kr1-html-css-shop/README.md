# kr1-html-css-shop — Винтаж-лавка

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина винтажных вещей. Только HTML и CSS: без CSS-фреймворков и без JavaScript.

HTML5, CSS3 (переменные, Flexbox, Grid, `position`), БЭМ, GitHub Pages.

## Как посмотреть проект

Откройте `index.html` в браузере или перейдите по ссылке GitHub Pages выше.

## Страницы

| Страница        | Содержимое                                                                  |
| --------------- | --------------------------------------------------------------------------- |
| `index.html`    | hero, якорные ссылки, преимущества, популярные товары, контакты             |
| `catalog.html`  | блок фильтров (`aside`), карточки товаров, модальное окно быстрой заявки    |
| `product.html`  | изображение, описание, цена, таблица сравнения                              |
| `order.html`    | форма: имя, e-mail, телефон, товар, сообщение, согласие, кнопка «Отправить» |
| `contacts.html` | адрес, телефон, e-mail, часы работы                                         |

Единое меню: Главная, Каталог, Контакты. Блок «О нас» находится в подвале каждой страницы. Якоря на главной: `#advantages`, `#catalog`, `#about` (подвал), `#contacts`.

## Где что реализовано

- Семантика: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.
- Карточки: `.product-card`, `__img`, `__title`, `__desc`, `__price`, `__button`, `__badge`.
- Таблица: `caption`, `thead`, `tbody`, `th`, `td`.
- Переменные: блок `:root` в начале `css/style.css`.
- Состояния: `:hover`, `:focus-visible`, `:disabled`.
- Flexbox: меню, кнопки, преимущества, страница товара. Grid: сетка карточек, раскладка каталога.
- Позиционирование: `relative` (карточка), `absolute` (бейдж, крестик модалки), `sticky` (шапка), `fixed` и `z-index` (модальное окно).
- Модальное окно сделано на CSS через `:target`, без JavaScript.

## Самостоятельные доработки

Бейдж на карточке, статический блок фильтров, модальное окно на чистом CSS, закреплённая шапка.
